
# Lesson 03: Java int Data Type

## 1. What is int?

`int` is a primitive data type in Java used to store whole numbers.

Examples:
- Positive numbers
- Negative numbers
- Zero

## 2. Properties of int

- Size: 32 bits (4 bytes)
- Minimum value: -2,147,483,648
- Maximum value: 2,147,483,647

## 3. Syntax

```java
int variableName = value;
```

## 4. Example

```java
int age = 20;
int studentCount = 1500;
int population = 100000;
int temperature = -25;

System.out.println("Age: " + age);
System.out.println("Student Count: " + studentCount);
System.out.println("Population: " + population);
System.out.println("Temperature: " + temperature);
```

## 5. Important Points

- int stores whole numbers.
- int occupies 32 bits.
- It supports positive and negative values.
- It is commonly used for integer calculations.
- Values outside its range cannot be stored directly.
