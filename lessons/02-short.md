
# Lesson 02: Java short Data Type

## 1. What is short?

`short` is a primitive data type used to store whole numbers.

- Size: 16 bits (2 bytes)
- Minimum value: -32,768
- Maximum value: 32,767

## 2. Syntax

```java
short variableName = value;
```

## 3. Example

```java
short studentCount = 1500;
short examMarks = 950;
short year = 2026;

System.out.println(studentCount);
System.out.println(examMarks);
System.out.println(year);
```

## 4. Important Points

- short stores whole numbers.
- Its range is -32,768 to 32,767.
- Use short when a whole number is too large for byte but fits within short.
